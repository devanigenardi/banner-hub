## index.html

Typical HTML5 banner structure for ad servers:

- **`ad.size` meta tag**: Declares dimensions for the ad server (`<meta name="ad.size" content="width=300,height=250">`)
- **GSAP 3.11.1**: Animation library loaded from Google CDN
- **ScrollToPlugin**: GSAP plugin for ISI scrolling
- **OverlayScrollbars**: Custom scrollbar for the ISI drawer
- **ClickTag**: Click tracking system via `data-exit` attributes
- **ISI Section**: Collapsible safety information (required in pharma ads)

### DOM elements

```html
<div id="banner-wrapper">
  <div class="preloader">...</div>
  <div id="stage">
    <div data-exit="clickTag">      <!-- Main click area -->
      <div id="frame1">...</div>    <!-- Animation frames -->
      <div id="frame2">...</div>
      <div id="frame3">...</div>
    </div>
  </div>
  <div class="isi-container">       <!-- ISI drawer -->
    <div class="isi-header">...</div>
    <div class="isi-content">...</div>
  </div>
</div>
```

## banner-scripts.js (170 lines)

### Responsibilities

1. **Image preloading**: Loads all images from `imagesArray` before showing the banner
2. **GSAP wait**: Verifies GSAP and OverlayScrollbars are loaded
3. **Lazy loading**: Dynamically loads additional CSS/JS files
4. **ClickTag handler**: Reads `data-exit` attributes and sets up click tracking
5. **ISI drawer**: Controls open/close, auto-scroll, and exit triggers
6. **Anti-FOUC**: Prevents flash of unstyled content

### imagesArray

The `imagesArray` in banner-scripts.js is automatically regenerated by `forge.mjs` on every resize. It contains the list of all image files in the folder.

```javascript
var imagesArray = ["bg.jpg", "cta.png", "f1-txt-1.png", ...];
```

## styles.css

- Wrapper dimensions: `width: 300px; height: 250px`
- Absolute positioning for elements
- Overflow hidden on wrapper
- 3D transform setup (perspective)
- 1px border for ad compliance
- Centered preloader

## isi.css (170 lines)

ISI drawer system with CSS custom properties for configuration:

```css
:root {
  --isi-width: 300px;
  --isi-height: 250px;
  --isi-bg: #fff;
  --isi-font-family: Arial;
  --isi-font-size: 8px;
  /* ... more variables */
}
```

Includes:
- Collapsible header with animation
- Scrollable content area
- Custom scrollbar via OverlayScrollbars
- Open/closed states with CSS transitions
